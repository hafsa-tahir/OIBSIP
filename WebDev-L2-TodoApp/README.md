# TaskLedger — Advanced To-Do Application (OIBSIP)

A fully responsive, feature-rich To-Do web application built for the Oasis Infobyte Web Development Internship Program.

## 🛠️ Feature Checklist Compliance
- **CRUD Operations:** Complete functionality to Add, Edit, Delete, and toggle completion status of tasks.
- **Drag-and-Drop Reordering:** Built cleanly with the native HTML5 Drag and Drop API for smooth list sorting.
- **Categories & Tags:** Custom tagging system supporting *Work, Personal, Study, and Finance*.
- **Priority Levels:** Color-coded priority badges (*High, Medium, Low*).
- **Due Dates & Overdue Highlighting:** Automatic detection of overdue items with prominent visual flags.
- **Filter & Search:** Real-time query search and filtering by completion status (*All, Active, Completed*).
- **Persistence:** Local state saved seamlessly using browser `localStorage`.

## 🚀 Tech Stack
- **HTML5** (Semantic structure)
- **CSS3** (Modern layout, variables, flexbox/grid)
- **Vanilla JavaScript (ES6+)** (State management, event handling, HTML5 Drag & Drop API)
